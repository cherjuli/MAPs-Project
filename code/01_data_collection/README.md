# 01_data_collection

This folder contains the SEC EDGAR data ingestion and preprocessing notebooks.

## Files
- `Downloading_and_Parsing_Filings_final.ipynb`: downloads 10-K filings and parses filing content.
- `Preprocessing_Filings_final.ipynb`: cleans and preprocesses the parsed filing text for downstream MAP measurement.

## Suggested run order
1. `Downloading_and_Parsing_Filings_final.ipynb`
2. `Preprocessing_Filings_final.ipynb`
