# Data directory

## Included
- `external/`: shareable external inputs (e.g., MAP seed words, questionnaire artifacts).
- `processed/`: shareable derived outputs (e.g., MAP and MAP-fit firm-year scores), subject to licensing.

## Excluded from version control
- Raw SEC 10-K filing text
- Proprietary LSEG source datasets
- Annotated evaluation datasets containing substantial filing excerpts

Use placeholder files/README notes to document how excluded data can be obtained.
